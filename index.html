 函数格式

                    
支持箭头函数和普通函数两种格式：

                    

                        (index, data, source) => { ... }
                    

                    

                        function(index, data, source) { ... }
                    

                


                

                    
 参数说明

                    
    
                        
  • 
                            
                            index - 当前行索引（从0开始）
                        
    • 
                        
  • 
                            
                            data - 当前行数据对象（只读）
                        
    • 
                        
  • 
                            
                            source - 整个表的数据数组（只读，可选）
                        
    • 
                    

                


                

                    
 全局函数

                    

                        

                            update(index, newData)
                        

                        
更新指定行的数据，可多次调用合并更新

                    

                    

                        

                            yield(value)
                        

                        
输出一条结果，可多次调用产生多个结果

                    

                


                

                    
 自动补全

                    
    
                        
  • 
                            
                            输入 upd 或 yie - 补全函数名
                        
    • 
                        
  • 
                            
                            输入 data. - 补全顶级字段
                        
    • 
                        
  • 
                            
                            在 update(index, { }) 内 - 补全字段名
                        
    • 
                        
  • 
                            
                            换行后自动触发补全（在 update 参数内）
                        
    • 
                        
  • 
                            
                            输入 data.字典字段. - 补全字典子字段
                        
    • 
                        
  • 
                            
                            输入 data.条目字段. - 提示数组操作方法
                        
    • 
                        
  • 
                            
                            Ctrl+Space - 手动触发补全
                        
    • 
                    

                


                

                    
 快捷键

                    
    
                        
  • 
                            
                            Ctrl+Enter - 执行脚本
                        
    • 
                        
  • 
                            
                            Ctrl+J 或 Alt+/ - 手动补全
                        
    • 
                        
  • 
                            
                            Ctrl+/ - 切换注释（注释/取消注释选中行）
                        
    • 
                        
  • 
                            
                            Ctrl+S - 保存（根据当前面板自动保存）
                        
    • 
                        
  • 
                            
                            Shift+Alt+F - 格式化代码
                        
    •
