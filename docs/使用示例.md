## 示例 1：物品配置

**场景**：RPG 游戏的物品系统

### 第一步：创建枚举

**ItemType - 物品类型**
```
枚举类型: 数字枚举

WEAPON = 1          -- 武器
ARMOR = 2           -- 防具
CONSUMABLE = 3      -- 消耗品
MATERIAL = 4        -- 材料
QUEST = 5           -- 任务物品
```

**ItemRarity - 物品稀有度**
```
枚举类型: 数字枚举

COMMON = 1          -- 普通
UNCOMMON = 2        -- 优秀
RARE = 3            -- 稀有
EPIC = 4            -- 史诗
LEGENDARY = 5       -- 传说
```

**ItemQuality - 物品品质颜色**
```
枚举类型: 字符串枚举

COMMON = "gray"         -- 灰色
UNCOMMON = "green"      -- 绿色
RARE = "blue"           -- 蓝色
EPIC = "purple"         -- 紫色
LEGENDARY = "orange"    -- 橙色
```

### 第二步：创建 Schema

**ItemConfig - 物品配置表**

字段列表：
- `item_id` (数字) - 物品ID [必填]
- `item_name` (文本) - 物品名称 [必填]
- `item_type` (选项 - 关联枚举 ItemType) - 物品类型
- `rarity` (选项 - 关联枚举 ItemRarity) - 稀有度
- `quality_color` (选项 - 关联枚举 ItemQuality) - 品质颜色
- `icon_path` (文本) - 图标路径
- `description` (文本) - 描述
- `max_stack` (数字) - 最大堆叠数量，默认 1
- `price` (数字) - 售价
- `attributes` (字典) - 属性加成
  - `attack` (数字) - 攻击力
  - `defense` (数字) - 防御力
  - `hp` (数字) - 生命值
- `tags` (列表<文本>) - 标签

导出配置：
- 命名空间：`Config`
- 依赖包：`Enum`

```
max_stack: 1
```

```
  attack: 0
```

**消耗品**：

### 第四步：导出并使用

**导出的 Lua 代码**：

```lua
---@class Config.ItemConfig
---@field item_id integer 物品ID
---@field item_name string 物品名称
---@field item_type number 物品类型
---@field rarity number 稀有度
---@field quality_color string 品质颜色
---@field icon_path string 图标路径
---@field description string 描述
---@field max_stack integer 最大堆叠数量
---@field price integer 售价
---@field attributes table 属性加成
---@field tags table 标签

---@type Config.ItemConfig[]
local ItemConfig = {
    {
        item_id = 1001,
        item_name = "铁剑",
        item_type = Enum.ItemType.WEAPON,
        rarity = Enum.ItemRarity.COMMON,
        quality_color = Enum.ItemQuality.COMMON,
        icon_path = "items/sword_iron.png",
        description = "一把普通的铁剑",
        max_stack = 1,
        price = 50,
        attributes = { attack = 10, defense = 0, hp = 0 },
        tags = {"武器", "近战"},
    },
    -- ...更多物品
}

Config.ItemConfig = ItemConfig
return ItemConfig
```

**游戏中使用**：

```lua
local ItemConfig = require("Config.ItemConfig")

-- 创建物品数据管理器
local ItemManager = {}
ItemManager.items = {}

-- 初始化物品数据
function ItemManager:Init()
    for _, config in ipairs(ItemConfig) do
        self.items[config.item_id] = config
    end
end

-- 获取物品信息
function ItemManager:GetItem(itemId)
    return self.items[itemId]
end

-- 获取物品显示颜色
function ItemManager:GetItemColor(itemId)
    local item = self:GetItem(itemId)
    if item then
        return item.quality_color
    end
    return "white"
end

-- 使用示例
ItemManager:Init()
local sword = ItemManager:GetItem(1001)
print(sword.item_name)  -- "铁剑"
print(sword.attributes.attack)  -- 10
```

## 示例 2：关卡配置

**场景**：塔防游戏的关卡波次配置

### 第一步：创建枚举

**EnemyType - 敌人类型**
```
枚举类型: 数字枚举

SOLDIER = 1         -- 士兵
TANK = 2            -- 坦克
FLYER = 3           -- 飞行单位
BOSS = 4            -- Boss
```

### 第二步：创建 Schema

**EnemyConfig - 敌人配置表**

字段：
- `enemy_id` (数字) - 敌人ID
- `enemy_name` (文本) - 敌人名称
- `enemy_type` (选项 - 关联枚举 EnemyType) - 敌人类型
- `hp` (数字) - 生命值
- `speed` (数字) - 移动速度
- `reward` (数字) - 击败奖励

**LevelConfig - 关卡配置表**

字段：
- `level_id` (数字) - 关卡ID
- `level_name` (文本) - 关卡名称
- `waves` (条目) - 波次配置
  - `wave_num` (数字) - 波次编号
  - `enemy_id` (选项 - 关联表 EnemyConfig) - 敌人ID
  - `count` (数字) - 数量
  - `spawn_interval` (数字) - 生成间隔（秒）
  - `delay` (数字) - 延迟时间（秒）
- `total_time` (数字) - 总时长（秒）

### 第三步：填写数据

**敌人配置**：

```
enemy_name: 重型坦克
enemy_type: TANK

# Boss

enemy_name: 魔王
enemy_type: BOSS
hp: 5000
speed: 1.5
reward: 500
```

**关卡配置**：

```
level_id: 1
level_name: 第一关
waves:
  - wave_num: 1
    enemy_id: 1 (士兵)
    count: 5
    spawn_interval: 2
    delay: 0
    
  - wave_num: 2
    enemy_id: 1 (士兵)
    count: 10
    spawn_interval: 1.5
    delay: 10
    
  - wave_num: 3
    enemy_id: 2 (重型坦克)
    count: 2
    spawn_interval: 5
    delay: 25
    
  - wave_num: 4
    enemy_id: 99 (魔王)
    count: 1
    spawn_interval: 0
    delay: 40
    
total_time: 120
```

### 第四步：游戏中使用

```lua
local LevelConfig = require("Config.LevelConfig")
local EnemyConfig = require("Config.EnemyConfig")

-- 关卡管理器
local LevelManager = {}

function LevelManager:LoadLevel(levelId)
    -- 找到关卡配置
    local levelData = nil
    for _, level in ipairs(LevelConfig) do
        if level.level_id == levelId then
            levelData = level
            break
        end
    end
    
    if not levelData then
        error("关卡不存在: " .. levelId)
    end
    
    -- 开始波次
    for _, wave in ipairs(levelData.waves) do
        self:ScheduleWave(wave)
    end
end

function LevelManager:ScheduleWave(wave)
    -- 延迟后生成敌人
    Timer.After(wave.delay, function()
        for i = 1, wave.count do
            Timer.After((i - 1) * wave.spawn_interval, function()
                self:SpawnEnemy(wave.enemy_id)
            end)
        end
    end)
end

function LevelManager:SpawnEnemy(enemyId)
    -- 从 EnemyConfig 中获取敌人配置
    local enemyData = nil
    for _, enemy in ipairs(EnemyConfig) do
        if enemy.enemy_id == enemyId then
            enemyData = enemy
            break
        end
    end
    
    if enemyData then
        -- 创建敌人实例
        local enemy = Enemy.new(enemyData)
        enemy:Spawn()
    end
end
```

## 示例 3：商店系统

**场景**：游戏内商店配置

### 创建 Schema

**ShopConfig - 商店配置表**

字段：
- `shop_id` (数字) - 商店ID
- `shop_name` (文本) - 商店名称
- `shop_type` (选项) - 商店类型（手动配置：普通商店、高级商店、限时商店）
- `items` (条目) - 商品列表
  - `item_id` (选项 - 关联表 ItemConfig) - 物品ID
  - `price` (数字) - 价格
  - `discount` (数字) - 折扣（0.1 = 9折），默认 0
  - `stock` (数字) - 库存（-1 = 无限）
  - `level_required` (数字) - 等级要求
- `refresh_interval` (数字) - 刷新间隔（小时，0=不刷新）

### 填写数据

```
shop_id: 1
shop_name: 新手商店
shop_type: 普通商店
items:
  - item_id: 1001 (铁剑)
    price: 50
    discount: 0
    stock: -1
    level_required: 1
    
  - item_id: 3001 (生命药水)
    price: 10
    discount: 0
    stock: -1
    level_required: 1
    
  - item_id: 2001 (精灵护甲)
    price: 400
    discount: 0.2
    stock: 1
    level_required: 5
    
refresh_interval: 0


shop_id: 2
shop_name: 限时商店
shop_type: 限时商店
items:
  - item_id: 1002 (传说之剑)
    price: 9999
    discount: 0.5
    stock: 1
    level_required: 50
    
refresh_interval: 24
```

### 游戏中使用

```lua
local ShopConfig = require("Config.ShopConfig")
local ItemConfig = require("Config.ItemConfig")

local ShopManager = {}

function ShopManager:GetShop(shopId)
    for _, shop in ipairs(ShopConfig) do
        if shop.shop_id == shopId then
            return shop
        end
    end
    return nil
end

function ShopManager:CanBuyItem(player, shop, itemIndex)
    local item = shop.items[itemIndex]
    
    -- 检查等级
    if player.level < item.level_required then
        return false, "等级不足"
    end
    
    -- 检查库存
    if item.stock == 0 then
        return false, "已售罄"
    end
    
    -- 计算实际价格
    local finalPrice = item.price * (1 - item.discount)
    
    -- 检查货币
    if player.gold < finalPrice then
        return false, "金币不足"
    end
    
    return true, finalPrice
end

function ShopManager:BuyItem(player, shopId, itemIndex)
    local shop = self:GetShop(shopId)
    if not shop then
        return false, "商店不存在"
    end
    
    local canBuy, result = self:CanBuyItem(player, shop, itemIndex)
    if not canBuy then
        return false, result
    end
    
    local item = shop.items[itemIndex]
    local finalPrice = result
    
    -- 扣除金币
    player.gold = player.gold - finalPrice
    
    -- 添加物品到背包
    player:AddItem(item.item_id, 1)
    
    -- 减少库存
    if item.stock > 0 then
        item.stock = item.stock - 1
    end
    
    return true, "购买成功"
end
```

```lua
local SkillConfig = require("Config.SkillConfig")

local SkillManager = {}

function SkillManager:GetSkill(skillId)
    for _, skill in ipairs(SkillConfig) do
        if skill.skill_id == skillId then
            return skill
        end
    end
    return nil
end

function SkillManager:CastSkill(caster, skillId, level, target)
    local skillData = self:GetSkill(skillId)
    if not skillData then
        return false, "技能不存在"
    end
    
    -- 检查冷却
    if caster:IsSkillOnCooldown(skillId) then
        return false, "技能冷却中"
    end
    
    -- 检查魔法值
    if caster.mana < skillData.mana_cost then
        return false, "魔法值不足"
    end
    
    -- 获取等级数据
    local levelData = skillData.level_data[level]
    if not levelData then
        return false, "技能等级无效"
    end
    
    -- 计算伤害
    local damage = levelData.damage + 
                   caster:GetStat("magic_power") * skillData.damage_data.scaling
    
    -- 造成伤害
    target:TakeDamage(damage, skillData.damage_data.damage_type, caster)
    
    -- 应用效果
    for _, effect in ipairs(skillData.effects) do
        target:ApplyEffect(effect.effect_type, effect.duration, effect.value)
    end
    
    -- 消耗魔法
    caster.mana = caster.mana - skillData.mana_cost
    
    -- 进入冷却
    caster:SetSkillCooldown(skillId, levelData.cooldown)
    
    return true, "施法成功"
end
```

## 示例 5：事件系统

**场景**：游戏事件管理系统

### 创建事件枚举

**GameEvent - 游戏事件**

```
枚举类型: 事件枚举

PLAYER_LEVEL_UP = "OnPlayerLevelUp"
  注册参数:
    - playerId (integer) 玩家ID
  回调参数:
    - newLevel (integer) 新等级
    - oldLevel (integer) 旧等级

ITEM_OBTAINED = "OnItemObtained"
  注册参数:
    - itemType (string) 物品类型
  回调参数:
    - itemId (integer) 物品ID
    - count (integer) 数量
    - source (string) 来源

ENEMY_DEFEATED = "OnEnemyDefeated"
  注册参数:
    - enemyType (string) 敌人类型
  回调参数:
    - enemyId (integer) 敌人ID
    - killerId (integer) 击杀者ID
    - position (Vector3) 位置
    - reward (table) 奖励

QUEST_COMPLETED = "OnQuestCompleted"
  注册参数:
    无
  回调参数:
    - questId (integer) 任务ID
    - playerId (integer) 玩家ID
    - rewards (table) 奖励列表
```

### 游戏中使用

```lua
local GameEvent = require("Enum.GameEvent")

-- 事件管理器
local EventManager = {}
EventManager.listeners = {}

function EventManager:Register(eventName, ...)
    local args = {...}
    local callback = table.remove(args)  -- 最后一个参数是回调函数
    
    if not self.listeners[eventName] then
        self.listeners[eventName] = {}
    end
    
    table.insert(self.listeners[eventName], {
        args = args,
        callback = callback
    })
end

function EventManager:Trigger(eventName, ...)
    local params = {...}
    
    if not self.listeners[eventName] then
        return
    end
    
    for _, listener in ipairs(self.listeners[eventName]) do
        -- 检查注册参数是否匹配
        local match = true
        for i, arg in ipairs(listener.args) do
            if params[i] ~= arg then
                match = false
                break
            end
        end
        
        if match then
            -- 跳过已匹配的参数，传递回调参数
            local callbackParams = {}
            for i = #listener.args + 1, #params do
                table.insert(callbackParams, params[i])
            end
            listener.callback(table.unpack(callbackParams))
        end
    end
end

-- 使用示例

-- 注册玩家升级事件
EventManager:Register(
    GameEvent.PLAYER_LEVEL_UP,
    1001,  -- playerId
    function(newLevel, oldLevel)
        print(string.format("玩家升级：%d -> %d", oldLevel, newLevel))
        -- 解锁新技能、发放奖励等
    end
)

-- 注册物品获得事件（监听所有武器类型）
EventManager:Register(
    GameEvent.ITEM_OBTAINED,
    "weapon",  -- itemType
    function(itemId, count, source)
        print(string.format("获得武器 %d x%d，来源：%s", itemId, count, source))
        -- 更新成就、统计数据等
    end
)

-- 注册任务完成事件（监听所有任务）
EventManager:Register(
    GameEvent.QUEST_COMPLETED,
    function(questId, playerId, rewards)
        print(string.format("玩家 %d 完成任务 %d", playerId, questId))
        -- 播放特效、发放奖励等
    end
)

-- 触发事件
EventManager:Trigger(GameEvent.PLAYER_LEVEL_UP, 1001, 10, 9)
EventManager:Trigger(GameEvent.ITEM_OBTAINED, "weapon", 1001, 1, "treasure_chest")
EventManager:Trigger(GameEvent.QUEST_COMPLETED, 2001, 1001, {gold = 100, exp = 500})
```

## 总结

以上示例展示了配表系统在不同游戏场景中的应用：

1. **物品配置**：基础的数据表，使用枚举和字典
2. **关卡配置**：条目类型的应用，表与表之间的关联
3. **商店系统**：嵌套结构，关联多个配表
4. **技能系统**：复杂的多层嵌套和等级数据
5. **事件系统**：事件枚举的完整使用流程

### 共同特点

- **枚举先行**：定义好枚举，提高可读性
- **合理分表**：按功能模块拆分 Schema
- **关联引用**：通过 ID 关联不同配表
- **类型注解**：完整的 Lua 类型提示
- **易于维护**：结构清晰，扩展方便

### 最佳实践

1. **规划先行**：设计好数据结构再动手
2. **迭代优化**：随着需求变化调整 Schema
3. **文档齐全**：在描述字段中添加详细说明
4. **定期备份**：重要数据及时导出备份
5. **团队协作**：统一命名规范和组织方式
