# 配表编辑

## 界面说明

左侧边栏显示当前项目的所有表（schema），点击切换。

顶部工具栏:
- **新增行** - 添加一条数据
- **导出 Lua** - 导出当前表
- **导出全部** - 导出所有表和枚举

## 编辑数据

直接点击单元格编辑。不同字段类型有不同的编辑控件:

- **number** - 数字输入框
- **text** - 文本输入框
- **richtext** - 点击打开富文本编辑器
- **option** - 下拉选择
- **flags** - 多选复选框
- **color** - 颜色选择器
- **boolean** - 开关
- **datalist** - 可搜索下拉框
- **list** - 点击打开列表编辑器
- **entry** - 点击打开子表单

## 富文本编辑

富文本字段使用 Markdown 语法:

```markdown
# 大标题
## 二级标题
**加粗文本**
__下划线__
~~删除线~~
{c:red}红色文字{/c}
{c:#FF6600}自定义颜色{/c}
```

编辑器左侧写 Markdown，右侧实时预览效果。

## 删除数据

点击行首的删除按钮，确认后删除。

## 数据保存

所有修改自动保存。
