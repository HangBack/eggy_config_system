# 枚举管理

## 创建枚举

在 `schema/` 同级目录创建 `enum/` 文件夹，添加 JSON 文件。

### 普通枚举

```json
{
  "name": "ItemType",
  "description": "物品类型",
  "values": {
    "Weapon": 1,
    "Armor": 2,
    "Consumable": 3,
    "Material": 4
  }
}
```

使用: `{"type": "option", "enum": "ItemType"}`

### 标记枚举（flags）

用于多选场景，值为位索引（0, 1, 2...），导出时自动计算位运算结果。

```json
{
  "name": "ItemTag",
  "description": "物品标签",
  "isFlags": true,
  "values": {
    "Tradable": 0,
    "Stackable": 1,
    "Rare": 2,
    "Unique": 3
  }
}
```

使用: `{"type": "flags", "enum": "ItemTag"}`

选中 Tradable + Rare 时，导出值为 `5` (2^0 + 2^2)。

---

## 在 Schema 中使用

```json
{
  "type": {
    "label": "类型",
    "type": "option",
    "enum": "ItemType"
  },
  "tags": {
    "label": "标签",
    "type": "flags",
    "enum": "ItemTag"
  }
}
```

---

## 导出格式

枚举本身导出为 Lua:

```lua
-- ItemType.lua
return {
  Weapon = 1,
  Armor = 2,
  Consumable = 3,
  Material = 4,
}
```

flags 枚举导出:

```lua
-- ItemTag.lua
return {
  Tradable = 1,    -- 2^0
  Stackable = 2,   -- 2^1
  Rare = 4,        -- 2^2
  Unique = 8,      -- 2^3
}
```
