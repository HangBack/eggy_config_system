# 字段类型参考

## 基础类型

### number
数值类型。

```json
{"type": "number", "default": 0, "min": 0, "max": 100}
```

### text
普通文本，导出时不带引号。

```json
{"type": "text", "default": ""}
```

### text-raw
原始文本，导出时保留引号。

```json
{"type": "text-raw"}
```

### boolean
布尔值。

```json
{"type": "boolean", "default": false}
```

### timestamp
时间戳（精确到秒）。编辑时显示日期时间选择器（北京时区），导出为 Unix 时间戳整数。

```json
{"type": "timestamp"}
```

### color
颜色选择器，值为 `#RRGGBB` 格式。

```json
{"type": "color", "default": "#FFFFFF"}
```

## 富文本

### richtext
Markdown 语法编辑，转换为游戏内格式 `#f(code)...#l`。

```json
{"type": "richtext"}
```

语法对照:

| Markdown | 效果 | 导出格式 |
|----------|------|----------|
| `# 标题` | 一级标题 | `#f(h1)标题#l` |
| `## 标题` | 二级标题 | `#f(h2)标题#l` |
| `**文本**` | 加粗 | `#f(b)文本#l` |
| `__文本__` | 下划线 | `#f(u)文本#l` |
| `~~文本~~` | 删除线 | `#f(s)文本#l` |
| `{c:red}文本{/c}` | 颜色 | `#f(c:red)文本#l` |
| `{s:24}文本{/s}` | 字号 | `#f(s:24)文本#l` |

## 选择类型

### option（枚举引用）
下拉选择，值来自枚举定义。

```json
{"type": "option", "enum": "ItemType"}
```

### option（手动定义）
下拉选择，手动指定选项。

```json
{
  "type": "option",
  "options": [
    {"label": "简单", "value": 1},
    {"label": "普通", "value": 2},
    {"label": "困难", "value": 3}
  ]
}
```

### flags
多选标记，值为位运算结果。枚举需设置 `isFlags: true`。

```json
{"type": "flags", "enum": "ItemTag"}
```

### datalist
引用其他表的数据，显示为可搜索下拉框。

```json
{"type": "datalist", "source": "Skill", "valueField": "id", "labelField": "name"}
```

---

## 复合类型

### list
列表，可包含任意基础类型。

```json
{"type": "list", "itemType": "number"}
{"type": "list", "itemType": "text"}
```

### entry
嵌套对象，包含子字段。

```json
{
  "type": "entry",
  "fields": {
    "x": {"label": "X", "type": "number"},
    "y": {"label": "Y", "type": "number"}
  }
}
```

## 完整示例

```json
{
  "id": {
    "label": "ID",
    "type": "number",
    "primary": true
  },
  "name": {
    "label": "名称",
    "type": "text"
  },
  "description": {
    "label": "描述",
    "type": "richtext"
  },
  "type": {
    "label": "类型",
    "type": "option",
    "enum": "ItemType"
  },
  "tags": {
    "label": "标签",
    "type": "flags",
    "enum": "ItemTag"
  },
  "price": {
    "label": "价格",
    "type": "number",
    "default": 100
  },
  "color": {
    "label": "颜色",
    "type": "color",
    "default": "#FFFFFF"
  },
  "isEnabled": {
    "label": "启用",
    "type": "boolean",
    "default": true
  },
  "relatedSkill": {
    "label": "关联技能",
    "type": "datalist",
    "source": "Skill"
  },
  "rewards": {
    "label": "奖励列表",
    "type": "list",
    "itemType": "number"
  },
  "stats": {
    "label": "属性",
    "type": "entry",
    "fields": {
      "atk": {"label": "攻击", "type": "number"},
      "def": {"label": "防御", "type": "number"}
    }
  }
}
```
